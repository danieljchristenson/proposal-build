## The spreadsheet

Four columns. One row per project. Header row exactly as below:

| Project Name | Location | Year | Photo Filename |
|---|---|---|---|
| Pier 39 | San Francisco, CA | 2023 | pier39_evening.jpg |
| Oregon Zoo | Portland, OR | 2024 | zoolights_walkway.jpg |
| The Music Center | Los Angeles, CA | 2024 | musiccenter_plaza.jpg |

Notes per column:
- **Project Name:** the customer-facing name we'd put on the slide. Use the property name, not the legal entity. ("Pier 39" not "Pier 39 Limited Partnership".)
- **Location:** "City, ST" — two-letter state code.
- **Year:** the year we installed it. Just the 4-digit number.
- **Photo Filename:** the exact filename of the JPG in the `Photos/` folder. Must match character-for-character including the `.jpg` extension. Whatever the photo is named on your end, type that here.

If a project doesn't have a usable photo, leave it off the list. No empty photo cells.

## The `Photos/` folder

A flat folder — no subfolders. One JPG per project listed in the spreadsheet.

- **Format:** JPG only (not PNG, not HEIC, not RAW).
- **Size:** roughly 1200×800 pixels or larger. Landscape orientation is best (matches the tile shape on the slide).
- **Quality:** sharp, well-lit evening shot. No people in foreground if avoidable. No watermarks or logos burned in.
- **Filename:** anything you want — just make sure the spreadsheet's "Photo Filename" column matches exactly.

If you have multiple photos for a project, pick one. We can swap it later.

## Rules — read these carefully

1. **Past work only.** Only projects we've already installed in a prior season. If we're currently pitching the client this season, they don't go in here yet. Reason: this slide is social proof, and putting an active deal on it reads as inflated track record.

2. **Real customers only.** Every entry must be a real project we actually installed. No fictional names, no aspirational targets, no stand-ins.

3. **One photo per entry.** Don't include alternate shots in the folder — just the one we'd want on the proposal.
